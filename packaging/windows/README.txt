FaderFrame for Windows (portable)
=================================

Run bin\faderframe.exe. Nothing needs to be installed.

This copy is portable: settings, plugin caches, presets and the recordings
of unsaved projects are kept in the "FaderFrame Data" folder next to it, so
the whole folder can live on a USB stick. CLAP and VST3 plugins placed in
"FaderFrame Data\Plug-Ins\CLAP" and "FaderFrame Data\Plug-Ins\VST3" travel
with it (the usual plugin folders are searched as well). Delete
"FaderFrame Data" to use your profile's folders instead.

The installer (FaderFrame-<version>-windows-x64-setup.exe) installs FaderFrame
with Start menu entries and .ffproj file association instead.
