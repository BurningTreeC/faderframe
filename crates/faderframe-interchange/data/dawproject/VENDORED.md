# DAWproject schemas

`Project.xsd` and `MetaData.xsd` are the DAWproject 1.0 XML schemas from
<https://github.com/bitwig/dawproject> (branch `main`, fetched 2026-11-03),
unchanged. MIT licensed, © 2020 Bitwig: see `LICENSE-DAWproject.txt`.

They are only read by tests (`xmllint --schema`), never compiled in.
