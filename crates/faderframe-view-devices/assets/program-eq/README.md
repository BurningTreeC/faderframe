# Program EQ renders

The knob filmstrip, the knurled switch knob, the pilot lamp (lit and dark)
and the four mounting screws of the Program EQ's panel. They are PultEQFx's
renders by Simon Huber (generated by PultEQFx's `assetgen` under one
lighting rig), used in FaderFrame under the MIT licence.

| File | Pixels | |
| --- | --- | --- |
| `knob_large.png` | 176 × 8448 | 48 frames of 176 × 176 across the knob's 250° sweep |
| `knob_metal.png` | 320 × 320 | switch knob, never rotated (the pointer is drawn) |
| `lamp_lit.png`, `lamp_dark.png` | 256 × 256 | pilot lamp burning and out |
| `screw_1.png` … `screw_4.png` | 288 × 288 | each screw driven to its own angle |
